# Roboplanet Aktobe — сайт v4 «Предметная подача»

Статика: HTML + CSS + JS. Сборки нет, зависимостей нет, ключей и секретов нет.

## Размещение на Cloudflare Pages
- Репозиторий: `arturbaimuratov1-sys/demowebsiteroboplanet`
- Ветка для размещения: `main`
- Корневая папка проекта: `/` (корень репозитория)
- Команда сборки: _пусто (не требуется)_
- Каталог результата: `/`
- Версия Node.js: не требуется (статика без сборки)
- Переменные окружения: не требуются
- Пресет фреймворка в Cloudflare: `None`

Шаги: Cloudflare Dashboard → Workers & Pages → Create → Pages → Connect to Git → выбрать репозиторий → ветка `main` → Framework preset `None` → Build command пусто → Build output directory `/` → Save and Deploy. Файл `404.html` в корне Cloudflare подхватит автоматически для несуществующих адресов. Каждая страница — своя папка с `index.html`, поэтому прямые ссылки и обновление работают без `_redirects`.

## Страницы
- `/` — hero с предметным фото робота, панели Kids/Junior, процесс занятий, интерактивная фотополоса, CTA-полоса
- `/programs/` — табы Kids 4–12 / Junior 10–16 (меняются текст, фото, CTA), зеркальные панели, факты
- `/projects/` — крупный лид-кадр + 5 фото, фильтр, лайтбокс с клавиатурой
- `/about/` — сплит с фото + факты + широкое фото + FAQ-аккордеон
- `/contacts/` — адрес, телефон, WhatsApp, Instagram, карточка связи, карта и маршруты (форм нет)
- `404.html`
